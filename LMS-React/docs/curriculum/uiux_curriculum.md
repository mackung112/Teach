# การออกแบบส่วนติดต่อผู้ใช้ขั้นสูง (Advanced User Interface Design: 31901-2001)

## Unit 1: พื้นฐานและมโนทัศน์ UX/UI
- 1.1 นิยามและความแตกต่างของ UX และ UI
  - 1.1.1 นิยามของ User Experience (UX) ในระบบดิจิทัล
  - 1.1.2 นิยามของ User Interface (UI) และ visual elements
  - 1.1.3 ความเชื่อมโยงและส่วนเหลื่อมระหว่าง UX และ UI
- 1.2 ความสำคัญของงานออกแบบต่อธุรกิจ
  - 1.2.1 อิทธิพลของ UX/UI ต่อการตัดสินใจและการใช้บริการ
  - 1.2.2 การเพิ่มอัตราการคงอยู่ของผู้ใช้ (Retention Rate) ด้วยการออกแบบ
  - 1.2.3 กรณีศึกษาผลิตภัณฑ์ดิจิทัลที่สำเร็จด้วย UX/UI ขั้นสูง

ใบงานปฏิบัติ 1: วิเคราะห์และเปรียบเทียบข้อดี-ข้อเสียของ UX/UI ในผลิตภัณฑ์ดิจิทัลที่กำหนด

## Unit 2: แนวโน้มการออกแบบและนวัตกรรม UI
- 2.1 เทรนด์การออกแบบสมัยใหม่ (Modern Design Trends)
  - 2.1.1 การออกแบบและจัดการแสงสำหรับระบบ Dark Mode
  - 2.1.2 เทคนิคดีไซน์แบบ Glassmorphism และ Neumorphism
  - 2.1.3 การใช้ Microinteractions ยกระดับประสบการณ์ผู้ใช้งาน
- 2.2 การออกแบบเพื่อการเข้าถึงอย่างทั่วถึง
  - 2.2.1 หลักการออกแบบบนพื้นฐาน Mobile-First Design
  - 2.2.2 การออกแบบเพื่อทุกคน (Inclusive Design & Web Accessibility)

ใบงานปฏิบัติ 2: ออกแบบและจัดลำดับหน้า UI จำลองที่ตอบสนองกฎการเข้าถึงขององค์กร

## Unit 3: ทักษะเครื่องมือ Figma สำหรับดีไซเนอร์
- 3.1 การจัดการสภาพแวดล้อมการทำงาน
  - 3.1.1 การจัดการไฟล์ โครงสร้าง Page และการตั้งค่าเบื้องต้น
  - 3.1.2 การใช้งาน Frame ขอบเขต และระบบ Layer ขั้นสูง
- 3.2 การสร้างและจัดการส่วนประกอบ (Assets)
  - 3.2.1 การจัดการ Main Component และ Instance
  - 3.2.2 การสร้างและระบุสถานะองค์ประกอบด้วย Variants
  - 3.2.3 การสร้างและแชร์ Component Library ภายในทีม

ใบงานปฏิบัติ 3: สร้างและจัดระเบียบ UI Component Library และ Variants บนระบบ Figma

## Unit 4: กระบวนการวิจัยและทำความเข้าใจผู้ใช้
- 4.1 เทคนิคการวิจัยผู้ใช้ (User Research)
  - 4.1.1 การวางแผนและการสัมภาษณ์ผู้ใช้งานเชิงลึก (User Interview)
  - 4.1.2 การจัดทำแบบสอบถาม (Survey) และสังเกตการณ์ในสถานที่จริง
- 4.2 การสร้างตัวแทนและแผนที่ประสบการณ์
  - 4.2.1 การสร้างตัวตนจำลองของผู้ใช้งาน (User Persona)
  - 4.2.2 การวิเคราะห์ขั้นตอนและจุดเจ็บปวด (User Journey Mapping)

ใบงานปฏิบัติ 4: ร่างแผนการสัมภาษณ์ผู้ใช้และสร้าง User Persona พร้อมแผนภาพ User Journey Map

## Unit 5: กระบวนการคิดเชิงออกแบบ (Design Thinking)
- 5.1 การกำหนดโจทย์ปัญหา (Define)
  - 5.1.1 การวิเคราะห์และสังเคราะห์ข้อมูลเชิงลึก (User Insights)
  - 5.1.2 การระบุประโยค POV และกำหนดคำถาม How Might We (HMW)
- 5.2 การระดมสมองและต้นแบบเบื้องต้น (Ideate)
  - 5.2.1 กิจกรรม Crazy 8s และการทำ Brainstorming บน FigJam
  - 5.2.2 การสร้างและทดสอบต้นแบบอย่างง่าย (Paper Prototyping)

ใบงานปฏิบัติ 5: ดำเนินการระดมสมองด้วยกิจกรรม Crazy 8s และสร้างต้นแบบกระดาษแก้โจทย์ปัญหา

## Unit 6: จิตวิทยาการออกแบบและ Visual Hierarchy
- 6.1 กฎการรับรู้ภาพ (Gestalt Principles)
  - 6.1.1 การประยุกต์ใช้กฎ Proximity, Similarity และ Continuity
  - 6.1.2 การจัดวางองค์ประกอบสร้างลำดับความสำคัญ (Visual Hierarchy)
- 6.2 จิตวิทยาด้านการคิดและความรู้สึก
  - 6.2.1 การประยุกต์ใช้งาน Hick's Law และ Fitts's Law
  - 6.2.2 จิตวิทยาของสี (Color Psychology) และการออกแบบที่กระตุ้นอารมณ์

ใบงานปฏิบัติ 6: วิเคราะห์องค์ประกอบหน้าจอแอปพลิเคชันตามหลัก Gestalt Principles และ Hick's Law

## Unit 7: สถาปัตยกรรมข้อมูลและการไหลของผู้ใช้
- 7.1 การออกแบบโครงสร้างเนื้อหา (Information Architecture)
  - 7.1.1 การสร้างระบบแผนที่เว็บไซต์ (Sitemap) และเมนูนำทาง (Navigation)
  - 7.1.2 การจัดกลุ่มและจัดลำดับเนื้อหาด้วยเทคนิค Card Sorting
- 7.2 การออกแบบเส้นทางใช้งาน (User Flow)
  - 7.2.1 การเขียนแผนผังลำดับขั้นตอนการทำงาน (Flowchart)
  - 7.2.2 การตรวจสอบความลื่นไหลและแก้ไขจุดอับของระบบ

ใบงานปฏิบัติ 7: จัดทำแบบฝึก Card Sorting และพัฒนาสถาปัตยกรรมข้อมูลกับ User Flow

## Unit 8: การตอบโจทย์ Usability และ Design System
- 8.1 กฎการใช้งานได้ง่าย (Usability Heuristics)
  - 8.1.1 การประเมินหน้าจอระบบด้วย Nielsen's 10 Usability Heuristics
- 8.2 การสร้างระบบการออกแบบ (Design System)
  - 8.2.1 การจัดขนาดอักษร (Typography Scale) และคู่สีระบบใน Figma
  - 8.2.2 การวางเลย์เอาต์ด้วย Auto Layout และ Grid System

ใบงานปฏิบัติ 8: พัฒนาและประยุกต์ใช้ Design System (Grid, Color, Font Scale) ร่วมกับ Auto Layout

## Unit 9: การออกแบบการปฏิสัมพันธ์ (Interaction Design)
- 9.1 หลักการปฏิสัมพันธ์และแอนิเมชัน
  - 9.1.1 การกำหนดตัวสั่งงาน (Trigger) และผลลัพธ์ตอบกลับ (Feedback)
  - 9.1.2 การสร้างแอนิเมชันและทรานซิชันนุ่มนวลด้วย Smart Animate
- 9.2 การออกแบบท่าทางการสั่งงาน (Gesture Design)
  - 9.2.1 การกำหนดท่าทาง Tap, Swipe, Pinch และ Long Press บน Mobile UI

ใบงานปฏิบัติ 9: พัฒนา interactive prototype ที่เคลื่อนไหวแบบสมจริงด้วย Smart Animate

## Unit 10: การออกแบบ Wireframe และ Mockup
- 10.1 จากโครงร่างสู่ความสมจริง
  - 10.1.1 การสเก็ตช์ภาพโครงร่างความละเอียดต่ำ (Low-Fidelity Wireframe)
  - 10.1.2 การออกแบบ Mockup ความละเอียดสูงระดับ Pixel-Perfect (High-Fidelity)

ใบงานปฏิบัติ 10: เปลี่ยนผลงาน Low-Fi Wireframe ให้เป็น High-Fi Mockup ที่สมบูรณ์แบบ

## Unit 11: การทดสอบผู้ใช้และแผนภาพความต้องการ
- 11.1 การเตรียมและวิเคราะห์ความต้องการ
  - 11.1.1 การวิเคราะห์สเกลระบบผ่าน Use Case Diagram และ User Story
- 11.2 การทดสอบการใช้งานได้ง่าย (Usability Testing)
  - 11.2.1 ขั้นตอนทดสอบแบบ Think Aloud และการบันทึกข้อบกพร่อง
  - 11.2.2 การประเมินคุณภาพระดับความพึงพอใจด้วย System Usability Scale (SUS)

ใบงานปฏิบัติ 11: ดำเนินกิจกรรม Usability Testing กับกลุ่มเป้าหมายจริง และประเมินค่าคะแนน SUS

## Unit 12: การปรับปรุงวนซ้ำและการส่งต่องาน
- 12.1 กระบวนการพัฒนาวนซ้ำ (Iteration)
  - 12.1.1 การนำผลสะท้อนมาทำ A/B Testing และปรับปรุงต้นแบบ
- 12.2 การส่งต่อผลงานให้นักพัฒนา (Design Handoff)
  - 12.2.1 การใช้ Figma Dev Mode และสกัดทรัพยากร (SVG/PNG/CSS)

ใบงานปฏิบัติ 12: เตรียมไฟล์ Figma และทำการสกัด Assets แบบพร้อมนำไปติดตั้งโค้ดได้ทันที

## Unit 13: โครงงานและการนำเสนอขั้นสูง
- 13.1 การจัดเตรียมผลงาน (Portfolio)
  - 13.1.1 การจัดทำกรณีศึกษาการออกแบบ (UX Case Study) และ Pitch Deck
- 13.2 การนำเสนอและสาธิต (Presentation)
  - 13.2.1 การอธิบายแนวคิดเบื้องหลังการออกแบบและสาธิตสด (Live Demo Prototype)

ใบงานปฏิบัติ 13: นำเสนอผลงานความยาวจำกัด (Elevator Pitch) พร้อมนำส่ง Live Demo และ Case Study ของกลุ่ม
