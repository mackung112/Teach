## Unit 3: โครงสร้างข้อมูลแบบต้นไม้ (Tree)

- 3.1 ความรู้เบื้องต้นเกี่ยวกับโครงสร้างข้อมูลแบบต้นไม้
  - 3.1.1 Tree คืออะไรและทำไมจึงจัดเป็นโครงสร้างข้อมูลแบบไม่เป็นเส้นตรง (Non-Linear Data Structure)
  - 3.1.2 โครงสร้างความสัมพันธ์แบบลำดับขั้น (Hierarchical Relationship) ในระบบคอมพิวเตอร์ (เช่น ระบบโฟลเดอร์ในคอมพิวเตอร์ หรือโครงสร้าง DOM ใน HTML)
  - 3.1.3 คำศัพท์และส่วนประกอบสำคัญของต้นไม้ เช่น Node, Root, Parent, Child, Leaf Node, Edge, Height และ Depth
- 3.2 โครงสร้างต้นไม้แบบไบนารี (Binary Tree)
  - 3.2.1 Binary Tree คืออะไรและคุณสมบัติพื้นฐาน (มีลูกได้ไม่เกิน 2 โนด)
  - 3.2.2 ความแตกต่างระหว่าง Binary Tree ทั่วไป และ Binary Search Tree (BST)
  - 3.2.3 ข้อดีของ Binary Search Tree ในด้านการเพิ่มความเร็วในการค้นหา จัดเก็บ และจัดเรียงข้อมูล
  - 3.2.4 ข้อเสียและข้อจำกัดของ Binary Tree เช่น ปัญหาต้นไม้เอียง (Skewed Tree) ที่ทำให้ประสิทธิภาพลดลงเหลือเท่ากับ List
- 3.3 วิธีการท่องเข้าไปในต้นไม้ (Tree Traversal)
  - 3.3.1 แนวคิดการท่องเข้าไปในต้นไม้แบบลึกก่อน (Depth-First Search: DFS)
  - 3.3.2 การท่องแบบตามลำดับ (In-order Traversal: ซ้าย-ราก-ขวา) และการนำไปใช้
  - 3.3.3 การท่องแบบก่อนลำดับ (Pre-order Traversal: ราก-ซ้าย-ขวา) และการนำไปใช้
  - 3.3.4 การท่องแบบหลังลำดับ (Post-order Traversal: ซ้าย-ขวา-ราก) และการนำไปใช้
- 3.4 วิธีการสร้างและการใช้งานโครงสร้างต้นไม้ใน Python
  - 3.4.1 การสร้างโครงสร้าง Node และ Tree พื้นฐานโดยการประยุกต์ใช้ Class และ Object
  - 3.4.2 การเขียนฟังก์ชันเพื่อเพิ่มข้อมูล (Insert) และค้นหาข้อมูล (Search) ใน Binary Search Tree
  - 3.4.3 การเขียนฟังก์ชันเพื่อแสดงผลข้อมูลตามวิธี Tree Traversal แบบต่างๆ (In-order, Pre-order, Post-order)

## Unit 4: โครงสร้างข้อมูลแบบกราฟ (Graph)

- 4.1 ความรู้เบื้องต้นเกี่ยวกับโครงสร้างข้อมูลแบบกราฟ
  - 4.1.1 Graph คืออะไรและทำไมจึงจัดเป็นโครงสร้างข้อมูลแบบไม่เป็นเส้นตรง (Non-Linear Data Structure)
  - 4.1.2 โครงสร้างความสัมพันธ์แบบเครือข่าย (Network Relationship) ในระบบคอมพิวเตอร์ (เช่น ระบบเครือข่ายสังคมออนไลน์ หรือแผนที่ถนนในระบบนำทาง)
  - 4.1.3 คำศัพท์และส่วนประกอบสำคัญของกราฟ เช่น Node, Vertex, Edge, Directed Graph (Digraph), Undirected Graph, Weighted Graph และ Path
- 4.2 โครงสร้างกราฟแบบระบุทิศทาง (Directed Graph) และกราฟแบบไม่ระบุทิศทาง (Undirected Graph)
  - 4.2.1 ความแตกต่างระหว่าง Directed Graph และ Undirected Graph รวมถึงการนำไปใช้ในงานประเภทต่างๆ
  - 4.2.2 ข้อดีและข้อจำกัดของกราฟประเภทต่างๆ
- 4.3 การแทนที่กราฟในหน่วยความจำ (Graph Representation)
  - 4.3.1 การแทนที่กราฟโดยใช้เมทริกซ์ (Adjacency Matrix)
    - หลักการทำงานและการใช้งาน
    - ข้อดีและข้อจำกัด
  - 4.3.2 การแทนที่กราฟโดยใช้รายการเชื่อมโยง (Adjacency List)
    - หลักการทำงานและการใช้งาน
    - ข้อดีและข้อจำกัด
- 4.4 วิธีการท่องเข้าไปในกราฟ (Graph Traversal)
  - 4.4.1 แนวคิดการท่องเข้าไปในกราฟแบบกว้างก่อน (Breadth-First Search: BFS)
  - 4.4.2 การท่องแบบลึกก่อน (Depth-First Search: DFS)
- 4.5 การประยุกต์ใช้กราฟในการแก้ปัญหา
  - 4.5.1 การหาเส้นทางที่สั้นที่สุด (Shortest Path) โดยใช้อัลกอริทึม Dijkstra เบื้องต้น
  - 4.5.2 การหาเส้นทางในเกม (Maze Solving) โดยใช้ BFS หรือ DFS
  - 4.5.3 การหาองค์ประกอบที่เชื่อมต่อถึงกัน (Connected Components)

## Unit 5: อัลกอริทึมการจัดเรียงข้อมูล (Sorting Algorithms)

- 5.1 ความรู้เบื้องต้นเกี่ยวกับอัลกอริทึมการจัดเรียงข้อมูล
  - 5.1.1 ความสำคัญของการจัดเรียงข้อมูลในงานด้านคอมพิวเตอร์
  - 5.1.2 หลักการทำงานของอัลกอริทึมการจัดเรียงข้อมูล (Sorting Algorithm)
  - 5.1.3 สัญกรณ์ Big O และการวิเคราะห์ประสิทธิภาพของอัลกอริทึมการจัดเรียงข้อมูล
- 5.2 อัลกอริทึมการจัดเรียงข้อมูลแบบง่าย (Simple Sorting Algorithms)
  - 5.2.1 Bubble Sort (บับเบิลซอร์ต)
    - หลักการทำงานและการนำไปใช้
    - การวิเคราะห์ Big O และประสิทธิภาพ
  - 5.2.2 Selection Sort (ซีเล็กชันซอร์ต)
    - หลักการทำงานและการนำไปใช้
    - การวิเคราะห์ Big O และประสิทธิภาพ
  - 5.2.3 Insertion Sort (อินเสิร์ชันซอร์ต)
    - หลักการทำงานและการนำไปใช้
    - การวิเคราะห์ Big O และประสิทธิภาพ
- 5.3 อัลกอริทึมการจัดเรียงข้อมูลแบบประสิทธิภาพสูง (Efficient Sorting Algorithms)
  - 5.3.1 Merge Sort (เมิร์จซอร์ต)
    - หลักการทำงานแบบ Divide and Conquer และการนำไปใช้
    - การวิเคราะห์ Big O และประสิทธิภาพ
  - 5.3.2 Quick Sort (ควิกซอร์ต)
    - หลักการทำงานแบบ Divide and Conquer และการนำไปใช้
    - การวิเคราะห์ Big O และประสิทธิภาพ
  - 5.3.3 Heap Sort (ฮีปซอร์ต)
    - หลักการทำงานโดยใช้โครงสร้างข้อมูล Heap และการนำไปใช้
    - การวิเคราะห์ Big O และประสิทธิภาพ
- 5.4 อัลกอริทึมการจัดเรียงข้อมูลแบบพิเศษ (Special Sorting Algorithms)
  - 5.4.1 Counting Sort (เคาน์ติงซอร์ต)
    - หลักการทำงานและการนำไปใช้
    - ข้อจำกัดและกรณีที่เหมาะสมในการใช้งาน
  - 5.4.2 Radix Sort (เรดิกซ์ซอร์ต)
    - หลักการทำงานและการนำไปใช้
    - ข้อจำกัดและกรณีที่เหมาะสมในการใช้งาน
- 5.5 การประยุกต์ใช้และเปรียบเทียบประสิทธิภาพของอัลกอริทึมการจัดเรียงข้อมูล
  - 5.5.1 การเลือกใช้อัลกอริทึมการจัดเรียงข้อมูลให้เหมาะสมกับขนาดและลักษณะของข้อมูล
  - 5.5.2 การเปรียบเทียบประสิทธิภาพของอัลกอริทึมการจัดเรียงข้อมูลประเภทต่างๆ

  - 5.1.2 โครงสร้างความสัมพันธ์แบบเครือข่าย (Network Relationship) ในระบบคอมพิวเตอร์ (เช่น ระบบเครือข่ายสังคมออนไลน์ หรือแผนที่ถนนในระบบนำทาง)
  - 5.1.3 คำศัพท์และส่วนประกอบสำคัญของกราฟ เช่น Node, Vertex, Edge, Directed Graph (Digraph), Undirected Graph, Weighted Graph และ Path
- 5.2 โครงสร้างกราฟแบบระบุทิศทาง (Directed Graph) และกราฟแบบไม่ระบุทิศทาง (Undirected Graph)
  - 5.2.1 ความแตกต่างระหว่าง Directed Graph และ Undirected Graph รวมถึงการนำไปใช้ในงานประเภทต่างๆ
  - 5.2.2 ข้อดีและข้อจำกัดของกราฟประเภทต่างๆ
- 5.3 การแทนที่กราฟในหน่วยความจำ (Graph Representation)
  - 5.3.1 การแทนที่กราฟโดยใช้เมทริกซ์ (Adjacency Matrix)
    - หลักการทำงานและการใช้งาน
    - ข้อดีและข้อจำกัด
  - 5.3.2 การแทนที่กราฟโดยใช้รายการเชื่อมโยง (Adjacency List)
    - หลักการทำงานและการใช้งาน
    - ข้อดีและข้อจำกัด
- 5.4 วิธีการท่องเข้าไปในกราฟ (Graph Traversal)
  - 5.4.1 แนวคิดการท่องเข้าไปในกราฟแบบกว้างก่อน (Breadth-First Search: BFS)
  - 5.4.2 การท่องแบบลึกก่อน (Depth-First Search: DFS)
- 5.5 การประยุกต์ใช้กราฟในการแก้ปัญหา
  - 5.5.1 การหาเส้นทางที่สั้นที่สุด (Shortest Path) โดยใช้อัลกอริทึม Dijkstra เบื้องต้น
  - 5.5.2 การหาเส้นทางในเกม (Maze Solving) โดยใช้ BFS หรือ DFS
  - 5.5.3 การหาองค์ประกอบที่เชื่อมต่อถึงกัน (Connected Components)

## Unit 6: อัลกอริทึมการจัดเรียงข้อมูล (Sorting Algorithms)

- 6.1 ความรู้เบื้องต้นเกี่ยวกับอัลกอริทึมการจัดเรียงข้อมูล
  - 6.1.1 ความสำคัญของการจัดเรียงข้อมูลในงานด้านคอมพิวเตอร์
  - 6.1.2 หลักการทำงานของอัลกอริทึมการจัดเรียงข้อมูล (Sorting Algorithm)
  - 6.1.3 สัญกรณ์ Big O และการวิเคราะห์ประสิทธิภาพของอัลกอริทึมการจัดเรียงข้อมูล
- 6.2 อัลกอริทึมการจัดเรียงข้อมูลแบบง่าย (Simple Sorting Algorithms)
  - 6.2.1 Bubble Sort (บับเบิลซอร์ต)
    - หลักการทำงานและการนำไปใช้
    - การวิเคราะห์ Big O และประสิทธิภาพ
  - 6.2.2 Selection Sort (ซีเล็กชันซอร์ต)
    - หลักการทำงานและการนำไปใช้
    - การวิเคราะห์ Big O และประสิทธิภาพ
  - 6.2.3 Insertion Sort (อินเสิร์ชันซอร์ต)
    - หลักการทำงานและการนำไปใช้
    - การวิเคราะห์ Big O และประสิทธิภาพ
- 6.3 อัลกอริทึมการจัดเรียงข้อมูลแบบประสิทธิภาพสูง (Efficient Sorting Algorithms)
  - 6.3.1 Merge Sort (เมิร์จซอร์ต)
    - หลักการทำงานแบบ Divide and Conquer และการนำไปใช้
    - การวิเคราะห์ Big O และประสิทธิภาพ
  - 6.3.2 Quick Sort (ควิกซอร์ต)
    - หลักการทำงานแบบ Divide and Conquer และการนำไปใช้
    - การวิเคราะห์ Big O และประสิทธิภาพ
  - 6.3.3 Heap Sort (ฮีปซอร์ต)
    - หลักการทำงานโดยใช้โครงสร้างข้อมูล Heap และการนำไปใช้
    - การวิเคราะห์ Big O และประสิทธิภาพ
- 6.4 อัลกอริทึมการจัดเรียงข้อมูลแบบพิเศษ (Special Sorting Algorithms)
  - 6.4.1 Counting Sort (เคาน์ติงซอร์ต)
    - หลักการทำงานและการนำไปใช้
    - ข้อจำกัดและกรณีที่เหมาะสมในการใช้งาน
  - 6.4.2 Radix Sort (เรดิกซ์ซอร์ต)
    - หลักการทำงานและการนำไปใช้
    - ข้อจำกัดและกรณีที่เหมาะสมในการใช้งาน
- 6.5 การประยุกต์ใช้และเปรียบเทียบประสิทธิภาพของอัลกอริทึมการจัดเรียงข้อมูล
  - 6.5.1 การเลือกใช้อัลกอริทึมการจัดเรียงข้อมูลให้เหมาะสมกับขนาดและลักษณะของข้อมูล
  - 6.5.2 การเปรียบเทียบประสิทธิภาพของอัลกอริทึมการจัดเรียงข้อมูลประเภทต่างๆ
  - 6.5.3 การนำอัลกอริทึมการจัดเรียงข้อมูลไปประยุกต์ใช้ในงานจริง เช่น การจัดการฐานข้อมูลและการวิเคราะห์ข้อมูล
